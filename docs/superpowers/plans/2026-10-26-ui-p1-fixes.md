# TeamPulse UI P1 Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resolve the three P1 UI findings without adding backend scope or dependencies.

**Architecture:** Reuse current React routes, task query parameters, `TaskCard`, and browser storage. Each change stays inside its existing feature boundary and is covered by the nearest flow test.

**Tech Stack:** React 19, TypeScript, React Router, Vitest, Testing Library, CSS.

**Spec:** `docs/superpowers/specs/2026-10-26-ui-p1-fixes-design.md`

## Global Constraints

- Add no dependencies and change no backend/API contracts.
- Preserve permissions, URL-persisted task filters, exports, keyboard semantics, and 44px mobile targets.
- Do not touch unrelated `.obsidian` or browser-artifact files.

## Review Focus

- Member and Leader users must both reach valid mobile destinations without gaining new permissions.
- Active advanced filters must stay visible and removable after reload/deep-link.
- Needs-attention mode must preserve task-detail URLs and empty/error states.
- Browser storage must be scoped by normalized user email and tolerate unavailable storage.
- Waiting-state copy must not claim an invitation or request was sent.
