# Contribution Profile

Contribution Profile tổng hợp task được chấp nhận, merged PR, review, checks, estimate và activity. Nó là evidence profile hỗ trợ đánh giá, không phải điểm chất lượng tự động; commit count và Conventional Commit label không đủ để kết luận chất lượng.
