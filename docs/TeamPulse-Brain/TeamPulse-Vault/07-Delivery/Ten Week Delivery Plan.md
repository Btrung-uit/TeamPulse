# Ten Week Delivery Plan

1. **Weeks 1–2:** repository foundation, identity, workspace/project, ERD và design-system primitives.
2. **Weeks 3–4:** task/sprint workflow, permissions, activity log và tests nền.
3. **Weeks 5–6:** dashboard, Excel import/export, Resource Hub và Presentation Mode.
4. **Week 7:** integration hardening, frontend states và responsive monitoring.
5. **Week 8:** GitHub phase-2 slice nếu core đã đạt Definition of Done.
6. **Week 9:** integration/E2E tests, security pass, Docker và deployment.
7. **Week 10:** seed demo, README, diagrams, video demo và CV story.

Scope được điều chỉnh theo chất lượng core, không theo mong muốn nhồi đủ feature.
