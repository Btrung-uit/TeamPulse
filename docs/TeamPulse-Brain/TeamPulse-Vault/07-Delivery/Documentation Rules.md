# Documentation Rules

- README mô tả trạng thái thực tế, không claim feature chưa chạy.
- `CONTEXT.md` chỉ giữ canonical domain language, không chứa implementation detail.
- ADR chỉ ghi quyết định khó đảo ngược có trade-off thật.
- Vault dùng one-concept-per-note và wikilinks thay vì copy dài.
- Diagram/export đặt ngoài vault attachment nếu là artifact canonical.
- Code, tests và chạy thực tế là bằng chứng triển khai; note chỉ là kế hoạch cho đến lúc được xác minh.
