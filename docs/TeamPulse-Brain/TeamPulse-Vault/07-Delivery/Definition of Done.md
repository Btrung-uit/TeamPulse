# Definition of Done

Một feature Done khi:

- Acceptance criteria và permission behavior đã đúng.
- Happy path, validation, loading, empty, error và no-permission states tồn tại khi phù hợp.
- Test quan trọng chạy qua; không có secret hoặc known critical bug.
- Activity/audit effect được ghi đúng nếu feature thay đổi workflow.
- Responsive và keyboard behavior đã kiểm tra.
- Documentation/atomic note được cập nhật nếu domain hoặc decision thay đổi.
