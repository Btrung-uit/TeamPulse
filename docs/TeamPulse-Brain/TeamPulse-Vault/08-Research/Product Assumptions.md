# Product Assumptions

Các giả thuyết chưa được chứng minh:

- Nhóm sinh viên thấy context switching đủ đau để đổi workflow.
- Excel import làm onboarding nhẹ hơn nhập lại thủ công.
- Leader và member chấp nhận dùng Task Code trong commit/PR.
- Contribution Profile giúp minh bạch mà không tạo gamification xấu.
- Presentation Mode hữu ích trong buổi báo cáo.
