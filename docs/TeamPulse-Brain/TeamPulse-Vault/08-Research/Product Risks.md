# Product Risks

- TeamPulse trở thành một tab mới thay vì giảm context switching.
- Scope integrations làm core task workflow không hoàn chỉnh.
- Contribution metrics bị dùng như điểm số hoặc dễ gaming.
- External OAuth/webhook permissions làm demo phức tạp.
- Mobile bị biến thành desktop thu nhỏ.
- Documentation claim vượt quá implementation thực tế.

Mitigation chính: giữ MVP boundary, evidence profile không scoring, validation với nhóm thật và Definition of Done nghiêm túc.
