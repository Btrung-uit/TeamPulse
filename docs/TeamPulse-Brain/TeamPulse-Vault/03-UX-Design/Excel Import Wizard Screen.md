# Excel Import Wizard Screen

Wizard có bốn bước cố định: Upload → Map columns → Validate/Preview → Confirm. Preview hiển thị valid/warning/error counts, row-level issue và error-report download; lỗi chặn confirm, warning cần được leader chấp nhận.

Final confirmation nhắc rằng TeamPulse trở thành source of truth. Mapping/import là desktop/tablet-first; mobile không hỗ trợ.
