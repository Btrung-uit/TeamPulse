# Toast Component

Variants: success, info, warning, error, progress. Width `320–400`, radius `12`, tối đa ba toast; desktop top-right dưới topbar, mobile phía trên bottom navigation.

Success/info tự đóng sau khoảng 4 giây, warning 6 giây, actionable error giữ tới dismiss. Toast không thay inline field validation và phải dùng phù hợp `aria-live`.

Related: [[System UI States]], [[Accessibility and Motion]].
