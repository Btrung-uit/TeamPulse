# Application Shell

Desktop dùng sidebar `256px`, topbar `72px` và main padding `32px`. Sidebar nhóm Overview, Work, Engineering, Resources và Presentation; topbar chỉ giữ project context, search, notifications, theme và user menu.

Từ `1024px`, sidebar thu còn icon; dưới `768px`, navigation chuyển thành drawer/bottom navigation.
