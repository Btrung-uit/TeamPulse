# Input Component

Input height `40`, radius `10`, padding `12`; textarea min-height `96`. Anatomy: visible label → field with optional icons/actions → helper/error.

States: default, hover, focus, filled, error, disabled, read-only, searching. Placeholder không thay label; validation xảy ra khi blur/submit thay vì báo lỗi ngay ký tự đầu tiên.
