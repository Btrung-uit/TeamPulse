# Desktop First and Mobile Monitoring

Desktop là môi trường lập kế hoạch và quản trị đầy đủ. Mobile ưu tiên theo dõi và thao tác rủi ro thấp: Home, My Tasks, Inbox, PR status, resource links, comments và một số personal state transitions.

Mobile dùng card thay table, không drag Kanban, không bulk edit/import/integration setup hoặc destructive actions. Touch target tối thiểu `44 × 44px`.
