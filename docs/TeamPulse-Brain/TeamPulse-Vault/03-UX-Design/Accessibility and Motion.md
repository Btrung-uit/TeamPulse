# Accessibility and Motion

UI hướng tới WCAG AA, focus ring rõ, keyboard navigation, label thật cho input và status có icon/text thay vì chỉ màu. Motion kéo dài khoảng `150–300ms`, không gây layout shift và tôn trọng `prefers-reduced-motion`.
