# Component System

Foundation components gồm Button, Input, StatusBadge, TaskCard, Table, Modal, Toast và EmptyState. Mọi component phải có default, hover, focus-visible, loading, disabled và error/empty states phù hợp.

Thứ tự triển khai: Button/Input → StatusBadge → Modal/Toast → EmptyState → TaskCard → Table.
