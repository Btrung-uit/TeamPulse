# Primary Screens

Năm màn hình chính là:

1. Dashboard — tiến độ, rủi ro, task ưu tiên và activity.
2. Task Board — Kanban, filter và task creation.
3. Task Detail — properties, evidence, activity và comments trong side panel.
4. PR Waiting Room — review queue và GitHub deep links.
5. Presentation Mode — read-only summary cho audience.
