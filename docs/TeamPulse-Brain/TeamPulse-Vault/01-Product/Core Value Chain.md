# Core Value Chain

```text
Task → Evidence → Review → Contribution Report → Presentation
```

Mỗi capability mới phải củng cố ít nhất một mắt xích trong chuỗi này. Feature không giúp điều phối, minh chứng, review hoặc trình bày cần được xem là ngoài phạm vi.
