# Delivery Phases

- **MVP:** core work management, evidence, Excel onboarding, resources, presentation và Git guidance.
- **Phase 2:** GitHub App/webhook, PR Waiting Room, workflow automation, SignalR và notification nâng cao.
- **Phase 3:** Drive API, dependency visualization, advisor dashboard và analytics nâng cao.

Phase sau không được kéo feature vào MVP nếu core workflow chưa đạt [[Definition of Done]].
