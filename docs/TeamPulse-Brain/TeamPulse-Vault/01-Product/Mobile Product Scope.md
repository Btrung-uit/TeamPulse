# Mobile Product Scope

Mobile là monitoring-first: Home, My Tasks, Inbox, PR status, resources và một số cập nhật trạng thái cá nhân có rủi ro thấp.

Mobile không có quản trị workspace/member, Excel import/export, Kanban drag-and-drop, bulk edit, dependency editing, integration setup, Git Command Generator hoặc destructive actions.
