# MVP Scope

MVP gồm:

- Identity, workspace, project, membership và role.
- Task, sprint, deadline, Kanban, activity log và evidence link.
- Dashboard tiến độ và workload cơ bản.
- Excel import có mapping/preview/confirm và export `.xlsx`.
- Resource Hub dạng metadata/link.
- Presentation Mode.
- Git Command Generator chỉ tạo hướng dẫn copyable.

GitHub App/webhook, realtime nâng cao và Google Drive API không chặn việc phát hành MVP.
