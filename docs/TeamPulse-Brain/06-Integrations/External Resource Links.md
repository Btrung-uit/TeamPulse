# External Resource Links

Resource Hub lưu title, type, URL/external ID, owner, linked task và timestamps cho Docs, Drive, Canva, GitHub và demo. MVP mở đúng external service để edit; richer metadata sync thuộc phase sau.

TP-032 triển khai metadata CRUD nội bộ và chỉ chấp nhận absolute HTTP/HTTPS URLs. Việc link task dùng cho điều hướng/ngữ cảnh, không tự nâng Resource thành Evidence và không đồng bộ nội dung external.
