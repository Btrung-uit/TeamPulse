# Visual Language

TeamPulse dùng minimalism data-first với hai theme: Dark là Obsidian + Muted Gold; Light là Porcelain + Cool Silver. Gold/silver nhận diện thương hiệu, còn semantic colors vẫn biểu diễn success, warning, danger và info.

Bo tròn có kiểm soát, border mảnh, shadow ít và typography rõ; tránh cảm giác game/casino hoặc luxury landing page.
