# Button Component

Variants: Primary, Secondary, Ghost, Danger, Link, Icon-only. Heights: Small `36`, Medium `40`, Large `44`; radius `10`; icon `16–20`.

States: default, hover, active, focus-visible, loading và disabled. Loading giữ width và chặn double-submit; icon-only bắt buộc có tooltip và accessible label. Mỗi modal chỉ một primary action.
