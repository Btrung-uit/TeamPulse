# System UI States

Mọi data view cần loading skeleton, first-use empty state, filtered/search empty state, recoverable API error với Retry và no-permission state. Destructive hoặc bulk operations cần confirm modal nêu rõ hậu quả; inline validation không được thay bằng toast.
