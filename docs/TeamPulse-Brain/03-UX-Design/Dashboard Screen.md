# Dashboard Screen

Dashboard trả lời trong vài giây: project đang ở đâu, rủi ro gần nhất là gì và user cần làm gì tiếp theo.

Anatomy: page header/project context → KPI cards (progress, open, review, blocked, due soon) → sprint/status charts → My Priority Tasks → Recent Activity. Mobile chỉ giữ progress, due/blocked, tasks cá nhân và review cần hành động.
